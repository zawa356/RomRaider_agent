# Offline candidate preflight v1 (Phase VI, read-only)

`OfflineCandidatePreflight.inspect(enable, layout, expectedGeneration, expectedManifestSha, admission, orderedClasspath, approvedRLAP1, processId, nativeReader)` is default-off. Disabled calls do not inspect files. Enabled calls check approved offline entry (`Rlc2IntegrationCli`, never ProductBridgeWorker/Once), exact ordered RLAP1 JAR/runtime/bitness description, active RLDT1 generation, exact expected manifest bytes and explicit physical Source admissions against actual projection.

The preflight only observes already-existing legacy Worker, payload Lane and Publication locks through read-only shared handles, retained through projection and final checks. Missing/unknown/busy evidence refuses. It creates no lock/DB/file, takes over no process and performs no ingestion, send, formal ACK, recovery or activation. The expected description is an operator-supplied content expectation, not signature or distribution authenticity. A missing/replaced/reordered JAR or unexpected runtime refuses before reading the deployment.

Every result is `state=BLOCKED`, `launch_authorized=false`, `production_authorized=false`, `ack_eligible=false`. `prerequisites_matched=true` means only the checks described above completed; writer absence is still `WRITER_UNPROVEN`. Windows running-process provenance remains `UNKNOWN_PROCESS_PROVENANCE`, independently of matching JAR descriptions. `ArtifactProvenance.inspectProcess` is used for OS evidence, never a classpath self-report.

Independent JSON axes: product_mode, legacy_worker, lane_owner, publication_lock, deployment_generation, manifest_floor, source_admission, artifact_provenance, cursor_provenance, vault_integrity, staged_rli2_integrity, process_provenance, writer_quiescence, directory_durability, formal_ack. Uninspected cursor/Vault/staged integrity remains UNKNOWN; formal_ack is DISABLED. Reports contain only fixed codes/statuses and generation, no paths, payload, credentials, DSN, tokens or process command lines.

VI-3 is **Partial**: this is an executable read-only preflight, not a launcher. No normal launch is authorized while required writer/process evidence remains unknown. Old direct low-level APIs and historic binaries remain operationally excluded, not globally fenced. Normal offline child launch, verifier-owned artifact capabilities and end-to-end stale-clone launch acceptance remain deferred. VI-5 is Partial too: individual readiness axes exist, while Vault/cursor/staging checks remain separate RLPC1 inspections.
